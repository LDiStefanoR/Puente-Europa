# 📚 DOCUMENTACIÓN DEL PROYECTO

Esta carpeta contiene toda la documentación técnica y de configuración del proyecto.

---

## 📋 ARCHIVOS INCLUIDOS

### 1. **PROMPT_CARGAS_OFERTAS.md**
Guía completa para cargar nuevas ofertas de trabajo en el sitio web.

**Contenido:**
- Estructura de una oferta
- Reglas importantes (nombres genéricos, nivel de inglés, etc.)
- Formatos problemáticos a evitar
- Variación de lenguaje entre ofertas
- Proceso de carga paso a paso
- Ejemplos completos

**Cuándo usar:** Cada vez que se necesite agregar una nueva oferta de trabajo.

---

### 2. **CHECKLIST_CONTACTO.md**
Checklist de verificación de toda la información de contacto del sitio.

**Contenido:**
- Información de contacto actual (teléfonos, redes sociales, ubicación)
- Verificación por componente
- Formato de números para WhatsApp
- Ubicaciones donde debe aparecer cada dato
- Instrucciones para futuras actualizaciones

**Cuándo usar:** Para verificar o actualizar información de contacto.

---

### 3. **CONFIGURACION_SERVICIOS.md**
Configuración de servicios externos y credenciales.

**Contenido:**
- Configuración de email (ImprovMX)
- Direcciones de correo configuradas
- Acceso a servicios
- Configuración de DNS
- Información de planes y limitaciones

**Cuándo usar:** Para consultar o actualizar configuración de servicios externos.
